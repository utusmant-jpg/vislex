# VisLex workspace design

Reference: C:/Users/Muhammad Tariq - ONU/Downloads/DESIGN-linear.app.md.

Use #010102 for the conversation canvas, #0f1011 for the sidebar and custom Windows chrome, #141516 for the composer and elevated controls, #23252a for dividers, #f7f8f8 for primary text, #8a8f98 for secondary text and #5e6ad2 for the single accent. Original document pages, photographs and video retain their actual colors.

Cases are compact collapsible sections. Show five short chat rows initially, with Show more and keyboard-accessible delete controls. Delete is reversible via Undo and never cascades into original evidence or derived case records. Files live in a searchable popover and open as individually closable tabs beside the conversation.

The main view has no database status footer, technical source accounting, hashes, processing buttons or preservation slogans. Transcripts are available on demand. Archive operations live under the case menu. Processing, exact locators, evidence safeguards and versioned edits remain coordinator capabilities.

The composer displays a small current-file context chip. A message carries the selected file, displayed PDF page or media playback time to the agent after scope validation. The agent's typed open_source tool can open that source in the viewer; opening does not imply inspection. The agent can still inspect originals, revisit video, transcribe and edit working records through its existing tools.

Use a draggable custom title bar with accessible Windows controls. Respect reduced motion and show action activity without invented completion percentages or fixed step counts.
