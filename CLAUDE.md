## Claude-led development team

Claude is the coordinator. Use `/team` and `docs/AGENT-TEAM.md` to delegate bounded development tasks to actual Codex CLI or OpenCode/Z.ai workers through `python scripts/agent_team.py`. Use `doctor` before dispatch. Codex uses only `gpt-6-sol` or `gpt-6-astra` with ChatGPT authentication; GLM uses only `zai-coding-plan/glm-5.3`. Never switch Claude's provider to Z.ai or insert development credentials into VisLex.

Choose model and reasoning for each task, explicitly passing `--model` for Codex and `--reasoning` for both. For GLM-5.3 use low for simple bounded work, high for normal coding/review, and max for difficult debugging or complex correctness work. For Codex use GPT-6 Sol with low/medium for straightforward work and high for substantial implementation. Use GPT-6 Astra with high/xhigh for difficult architecture, security, concurrency and independent reviews; use max when sustained difficult reasoning is warranted. Escalate when uncertainty or unresolved failures justify it. Do not lower model quality merely because a quota is exhausted or silently switch billing/providers. State the selected model, effort and brief reason before dispatch; the launcher records actual selections in run metadata. These are starting guidelines, not a spending cap.

Every task packet must state the task, owned files, invariant, acceptance checks, and expected report. Read-only reviews can use this checkout; builds require a separate registered worktree of this repository. Preserve uncommitted work. Use isolated worktrees and coordinate shared-file ownership before edits. Wait for actual worker results, inspect their diffs and test evidence, and request corrections before accepting them. When useful, have the other provider review a change, then perform your own final review. Do not force every trivial task through all three models.

Run the helper through the shell tool; background execution is supported by the host shell tool. It saves local events, usage, session IDs and results in ignored `.agent-team/runs/`. To stop a run, use its `cancel` command. Do not read credentials or expose case data. No API billing fallback, arbitrary spending ceiling, lower-quality model substitution, or bypass-permissions flag is part of this workflow. CLI delegation does not control existing Codex desktop chats.
